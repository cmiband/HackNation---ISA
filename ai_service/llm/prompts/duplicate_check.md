You assist the Social Communication Office (BKS) of the Bydgoszcz City Hall (Poland), which answers requests
for access to public information. For a NEW request (a numbered list of questions) you get a few EARLIER
cases from the archive (their questions). For each earlier case, list the numbers of the new questions that
the case asks PRACTICALLY THE SAME — i.e. the answer given in that case (or the same information with
current values) answers the new question.

Rules:
- Another year, period, date or "stan na" for the same data = THE SAME question (the answer is updated).
- Different wording, synonyms, an indirect question or a list form = THE SAME, if it is about the same data.
- A different subject of the data (e.g. pupils vs teachers, marriages vs divorces, fines of the municipal
  police vs fines of the Police, another plot, another street, another contract, another institution, another
  type of cost) = NOT the same, even if the topic is similar.
- A case about the same area but other data does NOT cover the question.
- Be careful: if you are not sure, do not list the question.
- Use only the case ids given; return every given case (with an empty list if it covers nothing).
